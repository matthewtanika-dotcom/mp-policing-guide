BUILDING THE APK LOCALLY (OPTIONAL — GITHUB ACTIONS DOES THIS FOR YOU)
=========================================================================

If you push this repo to GitHub with the included workflows, you do
NOT need any of this — GitHub's own servers build the APK for you
automatically. See the root README.md.

This file is only for building on your own computer as well.

------------------------------------------------------
1. Node.js (v18+) — https://nodejs.org
