BUILDING THE APK LOCALLY (OPTIONAL — GITHUB ACTIONS DOES THIS FOR YOU)
=========================================================================

If you push this repo to GitHub with the included workflows, you do
NOT need any of this — GitHub's own servers build the APK for you
automatically. See the root README.md.

This file is only for building on your own computer as well.

WHAT YOU NEED
------------------------------------------------------
1. Node.js (v18+) — https://nodejs.org
2. Android Studio — https://developer.android.com/studio

STEPS
------------------------------------------------------
Run these from inside the capacitor-project folder.

1. Copy the current web app into this project (root index.html etc.
   is the single source of truth — always run this after editing
   anything at the repo root):
   npm run copy-web

2. Install dependencies:
   npm install

3. Add the Android platform (only needed the first time):
   npx cap add android

4. Sync the web app into the native project:
   npx cap sync android

5. Open in Android Studio:
   npx cap open android

6. Build a debug APK — in Android Studio: Build menu -> Build App
   Bundle(s) / APK(s) -> Build APK(s).
   Output: android/app/build/outputs/apk/debug/app-debug.apk

7. Install it on your phone: copy the .apk across and open it,
   allowing "install unknown apps" when prompted.

RELEASE (SIGNED) BUILDS
------------------------------------------------------
The GitHub Actions release workflow produces a debug-signed APK,
fine for sideloading but not for the Play Store. For a properly
signed release build later, generate a signing key with keytool and
use Android Studio's Build -> Generate Signed Bundle / APK option.
Keep the keystore file and its passwords safe and out of the repo.
